# Cineflix
Cineflix UI (dark/light neumorphic) running on the OnBox engine.

Run: serve this folder over http (e.g. `npx serve` or deploy to Vercel/Netlify) and open index.html.
Files: index.html, cineflix.css, cineflix.js (app), utils.js + ads-config.js (from OnBox), sw.js, manifest.json, assets/.
Set your own TMDB key and Firebase config in utils.js (CONFIG).
